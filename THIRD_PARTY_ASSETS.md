# Third-Party Assets

## Quaternius Cyberpunk Game Kit

This branch bundles two mature environment modules by **Quaternius**:

- \`public/assets/models/quaternius/Platform_4x4.gltf\`
- \`public/assets/models/quaternius/Platform_2x1_Empty.gltf\`

License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

Original pack: [Cyberpunk Game Kit](https://quaternius.com/packs/cyberpunkgamekit.html)

The files are original embedded glTF assets from the kit. They were retrieved from the public [Chronos Rift source repository](https://github.com/amhndu/chronos-rift), which credits the same Quaternius pack. The repository does not edit their meshes, UVs, embedded textures, or materials. Runtime code only loads, clones, scales, rotates, positions, and assigns shadows to the models.

Procedural road surfaces, project labels, bioinformatics laboratory structures, rain, lights, rover geometry, props, and audio are project-original. See \`assets/manifest.json\` for the machine-validated provenance ledger.
