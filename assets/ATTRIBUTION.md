# Asset provenance

This branch bundles two original environment modules from the **Quaternius Cyberpunk Game Kit**:

- \`public/assets/models/quaternius/Platform_4x4.gltf\`
- \`public/assets/models/quaternius/Platform_2x1_Empty.gltf\`

Quaternius releases the pack under CC0 1.0. The runtime preserves the source meshes, materials, and embedded textures; it only clones and transforms the models and enables scene shadows.

The remaining laboratory structures, route surfaces, rover, props, rain, wet-surface pattern, collectible fragments, and short audio waveforms are generated by project code. \`assets/manifest.json\` is the machine-validated source of truth, and \`THIRD_PARTY_ASSETS.md\` records the human-readable source and retrieval path.

Every future model, texture, HDRI, or audio file must be recorded in the manifest before \`npm run assets:check\` can pass.
