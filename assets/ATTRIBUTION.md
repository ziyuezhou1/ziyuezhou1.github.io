# Asset provenance

This branch includes four comparison scenes under <code>/style-lab/</code>. Their visual subjects are mature CC0 assets; project code only loads, clones, scales, rotates, positions, and enables shadows.

- **Modern city:** nine original Kenney City Builder GLB files and the shared colormap.
- **Medieval:** eight original KayKit Medieval Hexagon building glTF files, binary buffers, and the shared atlas.
- **Space base:** nine original KayKit Space Base Bits glTF files, buffers, and the shared atlas.
- **Nature:** eight original KayKit nature glTF files, buffers, and the shared atlas.

The existing homepage still bundles two original Quaternius Cyberpunk Game Kit modules. Its remaining route, rover, rain, props, and short audio waveforms are generated by project code.

<code>assets/manifest.json</code> is the machine-validated provenance ledger. See <code>THIRD_PARTY_ASSETS.md</code> for source repositories and reuse details. Every future model, texture, HDRI, or audio file must be recorded before <code>npm run assets:check</code> can pass.
