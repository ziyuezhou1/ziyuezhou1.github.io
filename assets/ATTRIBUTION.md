# Asset provenance

The current vertical slice ships no third-party binary artwork. Its laboratory, transit terminal, rover, props, rain, wet-surface pattern, collectible fragments, and short audio waveforms are generated by project code at runtime.

The asset manifest is the source of truth for provenance. Any future GLB, texture, HDRI, or audio file must be listed there with author, source URL, license, and an explanatory note before it can pass the asset validation command.

Kenney and Poly Haven are approved CC0 sources for later authored Blender passes, but approval is not attribution: an asset must be documented individually when it is actually added.
